# 钢铁防线 · HTML 坦克大战

一款使用原生 HTML5 Canvas、CSS 和 JavaScript 制作的复古坦克大战。无需安装依赖，直接打开 `index.html` 即可游玩。

## 游戏特色

- 玩家坦克、敌军 AI、子弹与碰撞系统
- 可破坏砖墙、不可破坏钢墙和水域障碍
- 多关卡、计分、生命与基地防守机制
- 支持键盘与手机触控
- 响应式界面，可离线游玩

## 操作方式

- 移动：`WASD` 或方向键
- 开火：`空格`
- 暂停：`P`
- 重新开始：`R`

## 本地运行

直接双击 `index.html`，或在项目目录运行任意静态文件服务器：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 技术栈

原生 HTML / CSS / JavaScript，无第三方依赖。
